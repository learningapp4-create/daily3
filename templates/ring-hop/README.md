# Ring Hop

A bird sits on a spinning ring. Press Hop in when a star meets the bird. Catch enough stars and the moon opens. You can hop back out to catch ones you missed.

Space or Hop in. Arrow up hops out. P pauses. R starts again.

## Change the game

Edit `config.js`.

- `goalStars` — how many stars open the moon
- `catchDegrees` — how close a star must be to count
- `rings` — outside ring first. `radius`, `speed` (radians per second), `stars` (degrees around the ring)
- `colors` — sky, rings, stars, bird, moon
