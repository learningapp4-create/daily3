# daily3

Forkable 3D games for KS2 and KS3. Each folder in `templates/` is one game: open `index.html` with a static server, then change `config.js` and reload.

```
python3 -m http.server 8080
```

- [Dune Glide](templates/dune-glide/) — steer a marble over a sand dune
- [Ring Hop](templates/ring-hop/) — hop rings and catch stars
- [Beetle Path](templates/beetle-path/) — turn stones so a beetle reaches a flower
