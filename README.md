# daily3

Forkable 3D games for KS2 and KS3. Each folder in `templates/` is one game: open `index.html` with a static server, then change `config.js` and reload.

```
python3 -m http.server 8080
```

- [Dune Glide](https://luac42.github.io/daily3/templates/dune-glide/) — steer a marble over a sand dune
- [Ring Hop](https://luac42.github.io/daily3/templates/ring-hop/) — hop rings and catch stars
- [Beetle Path](https://luac42.github.io/daily3/templates/beetle-path/) — turn stones so a beetle reaches a flower
- [Pond Skip](https://luac42.github.io/daily3/templates/pond-skip/) — skip a stone to the far lily pad
- [Balloon Drift](https://luac42.github.io/daily3/templates/balloon-drift/) — match the balloon to the gardens
- [Plank Brook](https://luac42.github.io/daily3/templates/plank-brook/) — fit planks across the brook
- [Lantern Post](https://luac42.github.io/daily3/templates/lantern-post/) — set the lantern on the posts
- [Nest Row](https://luac42.github.io/daily3/templates/nest-row/) — match each egg to its nest
- [Path Gate](https://luac42.github.io/daily3/templates/path-gate/) — open the bars for the wagon
- [Dock Raft](https://luac42.github.io/daily3/templates/dock-raft/) — load a raft, then cross to the jetty
- [Sun Beam](https://luac42.github.io/daily3/templates/sun-beam/) — slide a lamp onto the pale flower
- [Door Pips](https://luac42.github.io/daily3/templates/door-pips/) — turn a key until the door opens
